# 码医(MediCode) — AI医疗DRG编码与病历质控系统

## 一、一句话概述

用AI自动完成住院病历的ICD-10诊断编码和DRG付费分组，同时做病历内涵质控——帮医院**不被医保扣钱**，帮医保基金**不被浪费**。

---

## 二、项目背景

### 2.1 DRG/DIP付费改革是国家级政策

- 2021年国务院办公厅发布《关于推动公立医院高质量发展的意见》，明确全面推行DRG/DIP付费
- 2025年底前，DRG/DIP覆盖所有符合条件的住院医疗机构
- 这意味着：**每一份病历的ICD编码，直接决定医院的收入**

### 2.2 医院面临的真实痛点

| 痛点 | 严重程度 | 数据 |
|------|---------|------|
| 编码员严重不足 | ★★★★★ | 全国缺口超10万人，一个三甲医院需要10+编码员 |
| 编码错误率居高不下 | ★★★★★ | 人工编码错误率10-15%，每错一个编码医院亏几千到几万 |
| 病历内涵质控缺失 | ★★★★☆ | 医生写病历不规范，质控全靠事后抽查，漏检率超60% |
| 医保飞检罚款 | ★★★★★ | 编码问题导致医保拒付/飞检罚款，动辄数百万 |

### 2.3 为什么能用AI解决

- ICD编码本质是**文本→编码**的映射问题，大模型天然擅长
- DRG分组是**规则引擎+概率判断**的组合，代码化可行
- 病历质控是**规则+语义理解**，NLP能覆盖80%以上的问题

## 三、产品定义

### 3.1 核心功能模块

**模块一：智能ICD编码引擎**
- 输入：住院病历全文（入院记录、病程记录、手术记录、出院小结）
- 输出：主要诊断编码 + 其他诊断编码 + 手术操作编码（ICD-10临床版 + ICD-9-CM-3）
- 核心技术：基于开源医学大模型微调的编码推荐 + 编码校验规则引擎

**模块二：DRG自动分组器**
- 输入：ICD编码结果 + 患者基本信息
- 输出：DRG分组结果 + 权重/费率 + 预估支付金额
- 核心技术：CHS-DRG分组方案代码化 + 高频争议分组AI辅助判断

**模块三：病历内涵质控引擎**
- 输入：病历全文
- 输出：质控缺陷清单（逻辑矛盾、遗漏项、不规范表述、编码-文本不一致）
- 核心技术：100+质控规则 + AI语义一致性检查

**模块四：数据驾驶舱**
- 全院DRG运营概览
- 科室/医生维度的CMI值、费用消耗指数、时间消耗指数
- 编码质控排行榜、高频缺陷分析

### 3.2 产品形态

- **Web应用**：面向编码员和质控人员的日常工作台
- **API服务**：可对接医院HIS/电子病历系统
- **一键部署**：支持医院私有化部署（数据不出院，符合医疗数据安全要求）

## 五、商业模式

### 5.1 收入模型

- **SaaS订阅**：根据医院床位数分级定价（500床以下 8万/年，500-1500床 15万/年，1500床以上 25万/年）
- **私有化部署**：一次性授权费 30-80万 + 年维保费 20%

### 5.2 市场空间

- 全国三级医院 3,200+、二级医院 10,000+
- 可及市场规模：3,000+ 医院 × 平均15万/年 = **45亿/年**
- 初期目标：第一年签约10家医院，第二年50家，第三年200家

---

## 六、竞争壁垒

1. **数据飞轮**：每多一家医院使用，ICD编码数据库和质控规则就更完善
2. **规则积累**：质控规则是硬壁垒，100条和1000条规则的质控准确率天差地别
3. **医学知识库**：构建的ICD编码→病历片段→DRG规则三位一体知识库难以复制
4. **先发优势**：目前市场上没有成熟的AI+DRG编码+质控一体化产品
