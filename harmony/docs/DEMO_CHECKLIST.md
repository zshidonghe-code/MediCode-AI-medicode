# MediCode HarmonyOS 演示验收清单

## 演示前

- 启动 MediCode 后端，并确认 Harmony 设备可以访问后端地址。
- 在 DevEco Studio 中打开 `C:\Users\Donghe\Desktop\MediCode\harmony`。
- 使用已配置签名的设备或模拟器运行 `entry` 模块。
- 使用竞赛演示账号登录；密码不写入源码、截图或录屏材料。

## 主路径

1. 输入或保留合成病历示例，点击“本地脱敏并创建审核”。
2. 点击“自动执行分析流程”，让 Agent 依次完成抽取、编码、质控和证据检查。
3. 在跨文书左右侧证据冲突处选择“以入院记录为准”。
4. 自动推进重新计算，点击“人工确认并导出报告”。
5. 展示脱敏摘要、编码建议、风险、证据和可追溯事件时间线。

## 必须展示的价值点

- 原始病历先在设备侧脱敏，再提交到内网 Agent。
- Agent 不绕过冲突，而是在证据不足时暂停并请求人工确认。
- 每一步有版本号、事件类型和时间线，报告保留未解决事项。
- 网络错误或版本冲突时，页面显示可恢复状态，不伪造成功结果。

## 备用方案

- 真机无法访问电脑 `127.0.0.1` 时，改用电脑局域网 IP。
- 后端不可用时，保留构建成功的 HAP 和录屏，不使用真实患者数据。
- 签名未配置时只能验证编译，不能作为最终安装包提交。
